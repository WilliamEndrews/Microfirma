📐 Technical Details

	Format : PNG sprite sheets
	Canvas Size size : 64 x 80
	Frame count per animation per direction : 8 frames

------------------------------------------------------------------------------------

⚙️ Instructions

	All Animations contain all variants for hairstyle, top clothing,
	bottom clothing, shoes, and body color.
	Each animation uses the same frame count across all parts.
	Assets are designed for easy layering (mix and match freely).

------------------------------------------------------------------------------------

🎮 Compatibility
	
	Unity
	Godot
	Any engine that supports sprite sheets

------------------------------------------------------------------------------------

🧱 Layering Order Guide

	To ensure correct visual results, layer the character parts 
	in the following order:

	[Body → Clothing (Shoes, Bottom, Top) → Hair → Accessories]

⚠️ Exception:   Top Clothing variants 13, 14, and 15 
		should be placed above the Hair layer

💡 Note : For best results, maintain consistent positioning 
	   when assembling characters to ensure proper alignment 
	   across all parts.
